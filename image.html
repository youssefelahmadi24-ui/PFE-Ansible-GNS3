Le flux de l'automatisation : de la définition déclarative au provisionnement réel.

Configuration

L'administrateur définit l'état souhaité dans des fichiers texte versionnables.

Orchestration

L'outil interprète le code et calcule les changements nécessaires.

Provisionnement

Les ressources sont créées ou modifiées automatiquement via API.
